# Project contract

Reference layout:
https://github.com/users/aiarranger/projects/3

The reference Project demonstrates the intended visual hierarchy:

- Project title: `Issue Map | <service>`
- primary view: `Map | Phase×Area`
- columns: UX / App / Platform / Data / QA / Ops
- rows/groups: M0, M1, M2...
- card state: Ready / Doing / Waiting / Blocked / Done
- separate work-queue view: `Next | 着手できる`
- table and board views are secondary

The map is the primary human-readable project representation.

Do not copy the example product's Milestones or Issues into another project.
Only copy the structure and visual conventions.
