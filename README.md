# Personal Service Issue Map

一般的な個人向けサービスを題材にした Issue Map のサンプルです。

テーマは「今日やること・習慣を管理する小さなWebサービス」。

## Source of truth

- `project.json`: Milestone / Category / dependency / manual state
- GitHub Issue open/closed: 完了状態
- Issue #25: CIが自動生成する Issue Map

## Categories

- UX: 人が何をして何が起きれば成功か
- App: 画面・操作
- Platform: 保存・日付処理などの基盤
- Data: 定義データ・ルール
- QA: 人が操作してゴール達成を確認
- Ops: 公開・運用

進捗率は使わず、Ready / Doing / Blocked / Done とMilestone状態を表示します。
